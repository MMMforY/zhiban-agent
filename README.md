# 知伴 · Personal Agent

一个可自行运行的个人 AI 伙伴原型：让持续对话拥有可追溯、可纠正的记忆。

这是从作者的私人 Agent 项目中提取的公开运行时，不是私人实例的备份。人格与使用者资料均替换为中性模板，数据库初始为空。项目不提供作者的 API、服务器、模型额度、聊天记录或私人语料。

## 运行

需要 Node.js 22.13+（使用内置 SQLite，建议 Node 22 的较新版本）。

```sh
npm ci
```

将 `.env.example` 复制为 `.env`，填写自己的 `LLM_BASE_URL`、`LLM_MODEL`、`LLM_API_KEY`，然后运行：

```sh
npm start
```

打开 http://127.0.0.1:3030/chat.html 进行对话；http://127.0.0.1:3030/ 查看记忆星图。没有模型配置时不会生成回复或使用作者服务，页面会明确提示。兼容 Chat Completions 接口；供应商需支持 `max_tokens`，自动记忆提取还需支持 JSON 输出。不是所有兼容服务都经过验证。

不要求自行训练模型，可以接入自己的服务账号或自建兼容接口。免密本地模型需要显式设置 `LLM_ALLOW_NO_KEY=true`。模型密钥仅在服务端 `.env` 中配置，不在网页输入。

## 当前功能

- 普通文字对话、最近 20 条消息上下文、SQLite 本地持久化。
- 人格核心和用户资料分层，运行时学习候选需审核；记忆来源追溯与纠正 API。
- Scribe 提取、Archivist 整理、Librarian 检索；低置信记忆隔离。
- 词法、实体、情节检索；可选自建 Chroma 与 embedding 服务提供语义检索。
- 普通对话记忆星图，查看实体及来源。它不是全部记忆层的完整可视化。
- 保留素材、日记记忆的数据结构与通用 API，但不带任何个人材料或导入、同步、服务器运维脚本。

公开版新增一个最小聊天入口。默认关闭自动后台记忆处理；在聊天页勾选「提取本轮记忆」可请求处理，可能产生额外模型调用。无需模型的星图初始为空。API 接口沿用 `/api/v1/`；可选 Hermes 适配接口保留，但不包含私人 Hermes 安装和连接配置。

## 配置和数据边界

- `.env`、`data/`、私钥、日志和 `blueprint-private/` 不进入 Git。
- 若需私人定制，先将 `blueprint/` 复制为 `blueprint-private/`，把 `B_GPE_ROOT` 改成该路径。不要直接把个人资料写入已跟踪的公开模板。
- 默认仅绑定本机。此项目是单用户原型，不具备多租户、用户账号、权限隔离或生产部署保障。不要直接向公网开放；远程自用采用自己的 SSH 隧道。
- `API_AUTH_TOKEN` 是独立的运行时访问令牌，不是模型 API Key。启用后在网页输入该令牌；仅保留在页面内存。
- 对话与相关记忆会发送到你配置的模型；启用 embedding 后，相关文本也会发送到你配置的 embedding 服务。模型供应商的数据政策由使用者自行选择。
- 对话会写入本地数据库。网页“新对话”只切换会话，不删除历史。

## 验证

```sh
npm test
python scripts/audit_public.py
```

测试使用模拟模型和隔离数据，不会验证真实模型的长期理解效果。原型不承诺记忆提取准确率、陪伴效果或生产安全性。
