# Attribution

Zhiban is a public runtime extraction from the author's private B-GPE personal-agent project. The private blueprint, user profile, memories, credentials and Git history are not included.

The Scribe → Archivist → Librarian memory architecture and constellation interaction are inspired by [ClaraShafiq/MemoryConstellations](https://github.com/ClaraShafiq/MemoryConstellations). Its MIT copyright and permission notice are preserved in `LICENSE`. This project does not claim those architectural ideas as wholly original.

The public edition adds a neutral companion blueprint, blank configuration, a minimal chat page, loopback-only startup, sanitized provider errors and a publication scanner. Runtime internals retain B-GPE and Hermes interface names for compatibility.

Third-party npm dependencies retain their own licenses.
